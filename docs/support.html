GameSphere Support

Last updated: September 16, 2026

Pair a Sunshine or Apollo PC once. Then Play from The Sphere — or join a friend without owning a host.

In the app: Settings → Help & Support (this FAQ, offline) and Settings → Legal.

Pairing (Add your PC)

  1. PC and phone/iPad on the same Wi‑Fi (or the same ZeroTier network).
  2. Sunshine or Apollo running. Open GameSphere → Add your PC.
  3. Tap the PC. GameSphere shows a PIN — type that PIN in the Sunshine window (not the other way around).
  4. After pairing, covers should fill The Sphere. Empty? Install Companion on the PC and refresh.

Forget a PC anytime in Settings → Your PC. That only removes the pairing on this device.

Companion (Import Tool)

The free desktop GameSphere Import Tool publishes Steam (and other) games into Sunshine/Apollo so The Sphere has real covers.

  1. Download the latest macOS, Windows, or Linux build from GitHub Releases.
  2. Install on the gaming PC, not on the iPhone.
  3. Let it write apps.json / Sunshine apps, then refresh the library in GameSphere.

Companion also hosts the always-on daemon used for join-PIN, co-op state, WAN helpers, and GameSphere Mic. Current public version at launch: v1.4.4.

Remote play (ZeroTier)

Router port forwards on eero often fail and are not required.

  1. Install ZeroTier on the phone and the PC.
  2. Join the same ZeroTier network.
  3. GameSphere detects 10.147.x (ZeroTier) or 100.x (Tailscale) and uses that path.
  4. If you launch off-home without the VPN, the app asks you to turn ZeroTier on instead of dumping a port list.

UPnP helpers in Companion never map Sunshine’s 47990 admin port.

Voice (party chat)

Pro hosts can enable in-stream party voice. It is a live UDP mix — not recorded.

  • Mute from the stream Share control (or the pad Share/Create button locally).
  • Mic level lives in Sound / Quick Settings and matches Mic-to-PC gain.
  • Guests need microphone permission on their device.

PC mic (GameSphere Mic)

Pro can send your phone mic into the PC so Steam, Discord, or a game hears you as GameSphere Mic (PipeWire virtual capture — not VBAN).

  1. Companion mic wizard on the host.
  2. In GameSphere, enable Mic to PC (Pro).
  3. On the PC, set the default / app input to GameSphere Mic.

Sunshine’s HDMI audio path stays on the TV/AVR. Do not attach extra AEC to HDMI.

On-screen controls (OSC)

Touch controls work without a pad. You can show, hide, and edit layout / opacity while streaming (Quick Settings / OSC editor). Layouts stay on device.

Shortcuts and launch URLs

  • The Sphere Play is unlimited on every plan.
  • gamesphere://launch from Shortcuts, MCON, Backbone-style apps, or Open URL is metered on Free (10/week) and Shortcuts+ (100/month), unlimited on Pro.
  • gamesphere://join guest links are never metered.
  • On-device Delta / RetroArch / App Store tiles are never metered.
  • Copy a launch URL from game detail. Cold start shows Waking → Connecting → Starting.

Shortcuts+ is $2.99/mo auto-renew. Pro is $14.99 once. Manage Shortcuts+ in Apple ID → Subscriptions. Restore purchases is in Settings.

Guests vs host

The host pays (Shortcuts+ or Pro) to send Invite / Share / Swap. Friends install GameSphere free.

  • Guests wait until the host Accepts.
  • Guests cannot Resume the host game, cannot Swap seats, and Leave does not cancel the host session.
  • Guest shelf is the shared catalog only.

Still stuck?

Settings → Report a problem opens GitHub issues. Include: device, iOS version, whether you are host or guest, and whether ZeroTier is connected. Do not paste API keys.
